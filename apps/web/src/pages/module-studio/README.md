# Module Studio page

Studio thiết kế đèn module dùng React/TypeScript/Three.js. `ModuleLampStudioPage` là shell lắp ráp; `ModuleSketchPage` là sketch workspace; `src/moduleStudio` chứa state/model helpers.

## File

- `index.ts`: exports route components.
- `../../ModuleLampStudioPage.tsx`: main module assembly UI.
- `../../ModuleSketchPage.tsx`: sketch UI.
- `../../moduleStudio/`: module catalog, geometry và persistence.
