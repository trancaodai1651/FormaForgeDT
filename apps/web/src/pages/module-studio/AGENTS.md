# Module Studio agent guide

Phạm vi: `/module-studio` và `/module-studio/sketch`. Chức năng gồm lắp module, khớp nối, sketch 2D và preview 3D.

- Geometry dùng `src/moduleStudio`; không copy engine vào page.
- Giữ mobile/tablet layout, drag/drop module, delete module và camera center.
- Gate: web build; nếu sửa geometry thì test package geometry và kiểm tra STL/preview.
