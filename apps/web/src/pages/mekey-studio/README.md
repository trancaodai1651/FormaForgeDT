# MeKey Studio

Admin-only batch nametag/keychain workspace inspired by the interaction model of Mekey3D. The page owns its React UI and a dedicated Manifold worker. It reuses the shared FormaForge viewer and multi-material 3MF exporter.

Validate the live preview, orbit/zoom/reset, single-model 3MF, and arranged print-bed 3MF after geometry changes.
