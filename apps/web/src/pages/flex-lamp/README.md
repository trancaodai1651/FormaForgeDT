# Flex Lamp page

Trang admin tạo lamp shade 3D từ pattern/image. React + TypeScript điều phối controls; Three.js/manifold helpers trong `../../flexLamp` tạo preview và mesh.

## File

- `index.ts`: public export.
- `../../FlexLampWorkspacePage.tsx`: page shell và control panel.
- `../../flexLamp/`: profile, pattern, mesh/export helpers.

Không đưa dữ liệu đăng ký/mua hàng vào trang này. Chỉ admin mới truy cập route hiện tại.
