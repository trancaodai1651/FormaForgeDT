# Home Item Creator

Protected admin workspace for creating hollow home-decor vessels with a ShaperLab-inspired workflow.

## Scope

- Three base shapes: cylinder, square and oval.
- Dimension controls for width, length, height, wall, base and corner radius.
- Linear/bulged profiles and upper taper.
- Five live procedural relief families: lines, spheres, waves, diamonds and dots.
- Grid/staggered distribution, quality controls, mask mode, material color and local design JSON.
- Community preset cards, filament recommendations and browser-local STL export at Fast/High/Ultra quality.

The route is protected by the existing `AdminRoute` and is available at `/#/admin/home-item`. The module uses the shared VN/EN provider so it follows the language selected outside the workspace.
