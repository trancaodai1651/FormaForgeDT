# Tulip Creator page

This boundary owns the admin-only `/admin/tulip-creator` lamp-shade generator.
Keep its controls, preview geometry, and STL export local to this folder. Use
the shared VN/EN `LanguageProvider`; do not create a private page language
state. Do not move Clicker or MultiColor geometry into this page.

After changes, run the web typecheck and build, then inspect the Three.js
preview and exercise the STL download path.
